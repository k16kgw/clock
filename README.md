# clock

現在時刻（日本時間）の表示と、学会用タイムキーパー（1鈴・2鈴・3鈴）のページ。

- 時計: **https://seminar.k16kgw.com/clock/**
- タイムキーパー: **https://seminar.k16kgw.com/clock/#timer**

## 時計

- 24 時間表示 `HH:MM:SS` と日付（例: `2026年11月8日（日）`）
- 端末のタイムゾーン設定に関係なく常に `Asia/Tokyo` で表示
- クリック / タップ / `F` キーで全画面

## タイムキーパー

- 1鈴・2鈴・3鈴の時刻を設定（既定 10:00 / 12:00 / 15:00、各鈴はオン/オフ可）
- 1鈴は 1 回、2鈴は 2 回、3鈴は 3 回鳴る（ブラウザで合成した鈴の音）
- PC ではタブが裏に回っていても時間どおりに鳴る（Web Audio の時計で事前に予約）。スマホでは画面を前面に出したまま使う
- 音が止まった場合（出力機器の切り替え・スリープなど）は「🔇 タップして有効化」を表示し、復帰時に予約し直す
- 実行中にページを再読み込みしても経過時間を引き継ぐ
- 表示はカウントアップ（経過時間）/ カウントダウン（残り時間）を設定で切り替え
- 鈴ごとに背景色が変化（通常 → 黄 → 赤 → 濃い赤）、3鈴後は超過時間を表示
- 実行中は画面のスリープを防止（対応ブラウザのみ）
- 設定はブラウザに保存

| キー | 動作 |
| --- | --- |
| Space | 開始 / 一時停止 |
| R | リセット |
| B | 鈴を 1 回鳴らす |
| F | 全画面 |

> 本番前に「設定 → テスト」で音量を確認してください。ブラウザの仕様上、最初の音は「開始」や「テスト」を押した後でないと鳴りません。

## 構成

```
index.html        マークアップ
css/style.css     スタイル
js/app.js         表示切り替え・全画面・キーボード
js/clock.js       時計
js/timer.js       タイムキーパー
js/settings.js    設定の保存・時間計算
js/bell.js        鈴の音（Web Audio）
```

依存ライブラリ・ビルド不要。GitHub Pages（`main` ブランチの root）で配信。
カスタムドメイン `seminar.k16kgw.com` はユーザーサイト `k16kgw.github.io` の設定を引き継ぐため、
このリポジトリには **`CNAME` ファイルを置かない**こと。

## ローカルで確認

ES modules を使うため、ファイルを直接開くのではなくローカルサーバー経由で開く。

```bash
python3 -m http.server 8123
```

ブラウザで http://localhost:8123/ を開く。
